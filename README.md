# CIT119-Final-Project-McCreary
An encounter builder for D&amp;D 5E. 
This program allows you to quickly build a balanced encounter for your table using a pre-loaded monster table and official difficulty table.

# Installation
To install the program, download the project files to your desired location.
Ensure the both necessary JSON files are in the same directory as Encounter Builder.py

# Running
To run this program, ensure you have Python installed.
- Open cmd
- Navigate to the directory of the downloaded project files
- Run ```py "Encounter Builder.py"```
 - Enter party size
 - Enter party level (average)
 - Enter Desired difficulty
 - Review generated encounter
 - Enter y or n to save the encounter
 - Encounters are saved to the same directory as the project files under the monster name
  - Ex. "Giant Rat.html"
